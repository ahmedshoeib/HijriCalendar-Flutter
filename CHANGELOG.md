# Changelog

## 1.0.0

- Add a portable calendar engine with Umm al-Qura, Islamic, Civil, and Tabular Foundation reference data for AH 1300–1600.
- Add manual adjustment, official month-start anchors, validated authority timelines, and named time zones.
- Add single, multiple, range, and read-only selection with inclusive bounds.
- Add an inline six-week Flutter calendar with styling, custom builders, events, disabled dates, Arabic/English, RTL, semantics, and keyboard/swipe navigation.
- Add a responsive example with Android, iOS, web, Windows, macOS, and Linux runners.
- Add independent Foundation/iOS reference fixtures, automated tests, and cross-platform CI builds.
- Keep distribution private through Git dependencies; pub.dev publication is disabled.
